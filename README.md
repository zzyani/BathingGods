# 신들의 손님맞이

> 신들이 방문하는 목욕탕에서 5일 동안 손님을 맞이하는 **2D 경영 + 탐험 시뮬레이션**
> 《센과 치히로의 행방불명》에서 영감을 받은 **비공식·비영리 팬게임** · 게임 기획/구현 포트폴리오

| 항목 | 내용 |
|---|---|
| 플랫폼 | PC 웹 (Chrome / Edge / Safari 최신) |
| 기술 | HTML · CSS · Vanilla JavaScript (Canvas 2D, WebAudio) — 외부 라이브러리 없음 |
| 그래픽 | 쿼터뷰(아이소메트릭) · 현재는 코드로 그린 플레이스홀더 → AI 에셋으로 교체 가능 |
| 조작 | WASD 이동 + 마우스 상호작용 |
| 분량 | 게임 내 5일 (하루 영업 약 3~4분 + 마감 정리) · 일반 엔딩 1종 / 특수 엔딩 1종 |

## 실행 방법

빌드 과정이 없습니다. 아래 중 하나로 실행하세요.

- `index.html` 을 브라우저로 직접 열기
- 또는 로컬 서버: `python3 -m http.server 8642` 실행 후 `http://localhost:8642`

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 이동 (한글 입력 상태에서도 동작) |
| 마우스 클릭 | 손님·탕·약재·단서와 상호작용. 멀리 있으면 자동으로 걸어감 |
| `Space` / `E` | 가장 가까운 대상과 상호작용 |
| `Space` (꾹) | 탕 패널에서 불 지피기 |
| `1`~`3` | 대화 선택지 (`Space`·`Enter`는 강조된 선택지) |
| `J` / `Esc` / `M` | 단서 수첩 / 일시정지 / 소리 |

## 게임 루프

```
손님 도착(접수대) → 주문 듣기(온도·약재) → 목욕탕 탐험·약재 채집
→ 탕 준비(불 지피기로 온도 맞추기 + 약재 넣기) → 손님 안내 → 목욕 → ★1~5 평가
→ 탕 청소 → (반복) → 영업 종료 정산 → 상점 업그레이드 → 다음 날
```

### 평가 공식 (`js/game.js` → `rate()`)

| 요소 | 감점 |
|---|---|
| 온도 차이 0~1°C | 없음 |
| 온도 차이 2°C / 3~4°C / 5°C 이상 | −1 / −2 / −3 |
| 요청 약재 누락 (가지당) | −2 |
| 요청하지 않은 약재 (가지당) | −1 |
| 인내심 25% 미만에서 응대 | −1 |
| 목욕 중 온도가 어긋난 시간 20% 초과 / 50% 초과 | −1 / −2 |
| 사이 나쁜 손님이 옆 탕에 | −1 (사이 좋으면 팁 +10냥) |

- 별점 1~5 → 보상 `별×8냥` (+5점이면 12냥 보너스), 점수 `별×20`
- 인내심이 바닥나 돌아간 손님 / 영업 마감 때 아직 대기 중이던 손님은 0점으로 평판에 반영

### 손님별 대기·목욕 시간 (`js/data.js` → `GUEST_TYPES`, 기획서 v2.0 기준)

| 손님 | 대기 | 목욕 | 손님 | 대기 | 목욕 |
|---|---|---|---|---|---|
| 강물 정령 | 90초 | 20초 | 버섯 할멈 | 75초 | 45초 |
| 돌거북 신 | 85초 | 50초 | 등롱 요괴 | 70초 | 30초 |
| 이끼 노인 | 80초 | 40초 | 연잎 개구리 신 | 65초 | 35초 |
| 여우불 아가씨 | 60초 | 30초 | 달토끼 | 40초 | 20초 |
| 학 선인 | 85초 | 45초 | 눈꽃 정령 | 75초 | 35초 |
| 호랑나비 아씨 | 70초 | 30초 | 방망이 도깨비 | 55초 | 25초 |

- 대기 시간은 손님을 안내(따라오기)하는 동안 멈춤 · 향로 업그레이드 시 +25%
- 얼굴 없는 손님의 목욕 시간은 30초

### 맵 구조: 목욕탕 ↔ 탐험 구역 (`js/data.js` → `SCENES`)

- **메인 목욕탕**: 접수대, 탕 4개(한 줄), 복도, 보일러실 — 손님은 항상 여기에만 있음
- **탐험 구역 2곳**: 정원(유자·쑥·연못·국화·솔잎) / 약재 창고(감초·계피·박하·대추·생강). 복도 왼쪽 끝의 문으로 드나들며, 문을 지나면 장면이 페이드 전환
- 탕 앞에서 약재까지 편도 약 5초 (가장 먼 유자나무는 약 6초)
- 정원(13×10)·약재 창고(12×10)의 빈 바닥은 앞으로 추가할 채집 지점(탕 재료) 자리
- 탐험 구역에 있는 동안에도 영업 시간·인내심·탕 냉각·목욕은 계속 진행 → 화면 위 **목욕탕 소식** 띠에 새 손님, 인내심 낮은 손님, 식는 탕, 장작 부족 등을 표시
- 따라오던 손님은 구역으로 따라오지 않고 자리로 돌아감
- 보일러실은 탕 재가열·장작 보충 부담 때문에 메인 목욕탕에 그대로 둠 (기획서 v2.0의 '완전 분리·편도 8초'를 줄인 절충안)

### 탕 온도 변화 · 보일러 (`js/data.js` → `TUB_COOL_RATE`, `BOILER`)

- 물을 받은 탕은 **12초에 1°C씩 식음** (최저 30°C). 입장 온도로 기본 평가, 목욕 중 온도 유지로 추가 평가
- 목욕 중 요청 온도에서 1.5°C 이상 벗어나면 손님이 "차가워!/뜨거워!" 불평 → 목욕 중인 탕을 클릭해 온도만 조절 가능
- 불 지피기는 **보일러 장작**을 소모 (불 지필 때 초당 4, 평소 초당 0.12). 장작이 떨어지면 가열 속도 35%
- 보일러실 가마를 클릭하면 1.2초 동안 장작을 넣어 100%로 채움

### 손님 궁합 (`js/data.js` → `GUEST_RELATIONS`, `TUB_NEIGHBORS`)

- 탕은 욕탕 안쪽 벽을 따라 한 줄로 배치 (네 번째 탕도 같은 줄 끝에 추가) · 옆 탕 관계: 탕1–탕2, 탕2–탕3, 탕3–탕4
- 사이 나쁨: 여우불 아가씨–강물 정령, 등롱 요괴–강물 정령, 돌거북 신–달토끼, 여우불 아가씨–연잎 개구리 신, 눈꽃 정령–여우불 아가씨, 눈꽃 정령–등롱 요괴, 방망이 도깨비–학 선인
- 사이 좋음: 이끼 노인–돌거북 신, 강물 정령–연잎 개구리 신, 버섯 할멈–이끼 노인, 달토끼–등롱 요괴, 학 선인–돌거북 신, 호랑나비 아씨–연잎 개구리 신, 방망이 도깨비–등롱 요괴
- 주문 카드·주문 대사·탕 툴팁에서 관계를 미리 확인 가능

### 약재 (`js/data.js` → `HERBS`, 12종)

| 구역 | 약재 (채집 지점) |
|---|---|
| 정원 | 유자(유자나무), 쑥(쑥밭), 창포·연꽃(연못), 국화(국화밭), 솔잎(소나무) |
| 약재 창고 | 감초·계피(선반), 박하(선반), 대추(항아리), 생강(바구니) |
| 보일러실 | 유황 소금(상자) |

- 새 약재를 주로 찾는 손님: 호랑나비 아씨(국화), 학 선인(솔잎), 방망이 도깨비(대추), 눈꽃 정령(생강)
- 기존 손님도 주문마다 40% 확률로 대신 찾음: 이끼 노인→솔잎, 버섯 할멈→대추, 여우불 아가씨→생강, 달토끼→국화 (새 손님은 반대로 기존 약재를 가끔 찾음)
- 4~5일차 '약재 두 가지' 주문의 두 번째 약재로도 등장

### 영업 마감 규칙 (기획서 v2.0 기준)

- 02:00이 되면 **신규 접객 차단**: 새 손님이 오지 않고, 대기 중인 손님은 돌아감
- **안내·입욕·목욕 중인 손님은 끝까지 마무리** 가능 (안내 중인 손님은 남은 대기 시간 안에서)
- 남은 손님이 모두 떠나면 정산 화면으로 넘어감

### 일차별 구성 (`js/data.js` → `DAYS`)

| 일차 | 손님 | 새 요소 |
|---|---|---|
| 1 | 3명 | 튜토리얼 힌트, 정원·연못 약재 |
| 2 | 4명 | 약재 창고 손님(버섯 할멈, 여우불 아가씨), 학 선인 등장 가능 |
| 3 | 5명 | 보일러실 약재, 호랑나비 아씨, **단서 2개**, 떠도는 그림자 연출 |
| 4 | 6명 | 약재 2가지 주문, 방망이 도깨비·눈꽃 정령, **단서 2개**(쪽지, 외로운 그림자) |
| 5 | 5명 + 얼굴 없는 손님 | **특별 선택** → 엔딩 분기 |

### 엔딩 분기

```
5일차 밤, 얼굴 없는 손님이 금을 내민다
├─ 금을 받는다 ─────────────┐
├─ 정중히 거절한다 ─────────┼─→ 일반 엔딩 (평판 등급 S/A/B/C 문장 + 선택별 후일담)
├─ 무시한다 ───────────────┘
└─ "금 대신 탕을 준비해 드릴게요" (단서 3개 이상일 때만 열림)
     ├─ 단서대로 37°C + 연꽃 탕 대접 → ★ 특수 엔딩 「얼굴 없는 손님의 미소」
     └─ 잘못된 탕 / 시간 초과 ───────→ 일반 엔딩
```

단서 텍스트가 정답(연꽃 향, 사람 체온 37°C)을 암시하므로, 그의 주문은 `???`로 숨겨져 있고 플레이어는 단서 수첩을 근거로 탕을 준비해야 합니다.

## 프로젝트 구조

```
index.html        HUD·모달 DOM 뼈대
css/style.css     UI 스타일 (종이·나무 톤)
js/data.js        ★ 기획 데이터: 맵, 약재, 손님, 일차, 단서, 업그레이드, 대사, 엔딩
js/engine.js      유틸, 아이소메트릭 좌표 변환, 입력, WebAudio 효과음, BFS 길찾기, 에셋 로더
js/render.js      쿼터뷰 렌더링: 바닥·벽·오브젝트·캐릭터·이펙트·말풍선 (깊이 정렬)
js/ui.js          HUD, 대화창, 탕 패널, 단서 수첩, 상점·정산·엔딩 화면
js/game.js        상태 관리, 영업일 루프, 손님 AI(상태 머신), 상호작용, 평가, 저장
```

### 구현 포인트

- **쿼터뷰 렌더링**: 월드 좌표(타일) ↔ 화면 좌표 변환, `x+y` 기준 깊이 정렬, 플레이어 앞을 가리는 벽 자동 반투명
- **마우스 피킹**: 바닥 투영 + 오브젝트 높이만큼 위로 훑는 방식으로 키 큰 오브젝트(나무, 선반)도 정확히 클릭
- **클릭 이동**: 멀리 있는 대상을 클릭하면 BFS로 경로를 찾아 걸어간 뒤 자동 상호작용
- **손님 AI 상태 머신**: `arriving → waiting → following → toTub → bathing → leaving`
- **데이터 주도 설계**: 밸런스·대사·맵 수정은 `data.js`만 고치면 됨
- **저장**: 매 영업일 시작 시 `localStorage` 자동 저장 → 타이틀의 "이어하기"

## AI 에셋으로 교체하기

`js/data.js` 맨 아래 `ASSET_MANIFEST`에 이미지를 등록하면 해당 캐릭터/오브젝트는 도형 대신 이미지로 그려집니다.

```js
const ASSET_MANIFEST = {
  chihiro:  { src: 'assets/chihiro.png',  w: 48, h: 64, ax: 0.5, ay: 0.95 }, // 발밑 기준
  kaonashi: { src: 'assets/kaonashi.png', w: 56, h: 90, ax: 0.5, ay: 0.97 },
  moss:     { src: 'assets/moss.png',     w: 44, h: 48 },                    // 손님 타입 키
  tree:     { src: 'assets/tree.png',     w: 90, h: 120, ay: 0.85 },         // 오브젝트 kind 키
};
```

- 캐릭터 키: `chihiro`, `kaonashi`, `moss` `lantern` `river` `mushroom` `fox` `turtle` `rabbit` `frog` `butterfly` `crane` `dokkaebi` `snow`
- 오브젝트 키: `tree` `pine` `patch` `shelf` `jar` `basket` `crate` `furnace` `counter` (탕은 상태 표현 때문에 코드 렌더 유지)
- 권장 규격: 투명 PNG, 쿼터뷰 시점, 타일 1칸 = 64×32px 기준
