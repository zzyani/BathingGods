# 신들의 손님맞이

> 신들이 방문하는 목욕탕에서 5일 동안 손님을 맞이하는 **2D 경영 + 탐험 시뮬레이션**
> 《센과 치히로의 행방불명》에서 영감을 받은 **비공식·비영리 팬게임** · 게임 기획/구현 포트폴리오

| 항목 | 내용 |
|---|---|
| 플랫폼 | PC 웹 (Chrome / Edge / Safari 최신) |
| 기술 | HTML · CSS · Vanilla JavaScript (Canvas 2D, WebAudio) — 외부 라이브러리 없음 |
| 그래픽 | 쿼터뷰(아이소메트릭) · 현재는 코드로 그린 플레이스홀더 → AI 에셋으로 교체 가능 |
| 조작 | WASD 이동 + 마우스 상호작용 |
| 분량 | 게임 내 5일 (하루 약 3~4분) · 일반 엔딩 1종 / 특수 엔딩 1종 |

## 실행 방법

빌드 과정이 없습니다. 아래 중 하나로 실행하세요.

- `index.html` 을 브라우저로 직접 열기
- 또는 로컬 서버: `python3 -m http.server 8642` 실행 후 `http://localhost:8642`

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 이동 (한글 입력 상태에서도 동작) |
| 마우스 클릭 | 손님·탕·약재·단서와 상호작용. 멀리 있으면 자동으로 걸어감 |
| `Space` / `E` | 가장 가까운 대상과 상호작용 |
| `Space` (꾹) | 탕 패널에서 불 지피기 |
| `1`~`3` | 대화 선택지 (`Space`·`Enter`는 강조된 선택지) |
| `J` / `Esc` / `M` | 단서 수첩 / 일시정지 / 소리 |

## 게임 루프

```
손님 도착(접수대) → 주문 듣기(온도·약재) → 목욕탕 탐험·약재 채집
→ 탕 준비(불 지피기로 온도 맞추기 + 약재 넣기) → 손님 안내 → 목욕 → ★1~5 평가
→ 탕 청소 → (반복) → 영업 종료 정산 → 상점 업그레이드 → 다음 날
```

### 평가 공식 (`js/game.js` → `rate()`)

| 요소 | 감점 |
|---|---|
| 온도 차이 0~1°C | 없음 |
| 온도 차이 2°C / 3~4°C / 5°C 이상 | −1 / −2 / −3 |
| 요청 약재 누락 (가지당) | −2 |
| 요청하지 않은 약재 (가지당) | −1 |
| 인내심 25% 미만에서 응대 | −1 |

- 별점 1~5 → 보상 `별×8냥` (+5점이면 12냥 보너스), 점수 `별×20`
- 인내심이 바닥나 돌아간 손님 / 영업 종료까지 못 맞이한 손님은 0점으로 평판에 반영

### 일차별 구성 (`js/data.js` → `DAYS`)

| 일차 | 손님 | 새 요소 |
|---|---|---|
| 1 | 3명 | 튜토리얼 힌트, 정원·연못 약재 |
| 2 | 4명 | 약재 창고 손님(버섯 할멈, 여우불 아가씨) |
| 3 | 5명 | 보일러실 약재, **단서 2개**, 떠도는 그림자 연출 |
| 4 | 6명 | 약재 2가지 주문, **단서 2개**(쪽지, 외로운 그림자) |
| 5 | 5명 + 얼굴 없는 손님 | **특별 선택** → 엔딩 분기 |

### 엔딩 분기

```
5일차 밤, 얼굴 없는 손님이 금을 내민다
├─ 금을 받는다 ─────────────┐
├─ 정중히 거절한다 ─────────┼─→ 일반 엔딩 (평판 등급 S/A/B/C 문장 + 선택별 후일담)
├─ 무시한다 ───────────────┘
└─ "금 대신 탕을 준비해 드릴게요" (단서 3개 이상일 때만 열림)
     ├─ 단서대로 37°C + 연꽃 탕 대접 → ★ 특수 엔딩 「얼굴 없는 손님의 미소」
     └─ 잘못된 탕 / 시간 초과 ───────→ 일반 엔딩
```

단서 텍스트가 정답(연꽃 향, 사람 체온 37°C)을 암시하므로, 그의 주문은 `???`로 숨겨져 있고 플레이어는 단서 수첩을 근거로 탕을 준비해야 합니다.

## 프로젝트 구조

```
index.html        HUD·모달 DOM 뼈대
css/style.css     UI 스타일 (종이·나무 톤)
js/data.js        ★ 기획 데이터: 맵, 약재, 손님, 일차, 단서, 업그레이드, 대사, 엔딩
js/engine.js      유틸, 아이소메트릭 좌표 변환, 입력, WebAudio 효과음, BFS 길찾기, 에셋 로더
js/render.js      쿼터뷰 렌더링: 바닥·벽·오브젝트·캐릭터·이펙트·말풍선 (깊이 정렬)
js/ui.js          HUD, 대화창, 탕 패널, 단서 수첩, 상점·정산·엔딩 화면
js/game.js        상태 관리, 영업일 루프, 손님 AI(상태 머신), 상호작용, 평가, 저장
```

### 구현 포인트

- **쿼터뷰 렌더링**: 월드 좌표(타일) ↔ 화면 좌표 변환, `x+y` 기준 깊이 정렬, 플레이어 앞을 가리는 벽 자동 반투명
- **마우스 피킹**: 바닥 투영 + 오브젝트 높이만큼 위로 훑는 방식으로 키 큰 오브젝트(나무, 선반)도 정확히 클릭
- **클릭 이동**: 멀리 있는 대상을 클릭하면 BFS로 경로를 찾아 걸어간 뒤 자동 상호작용
- **손님 AI 상태 머신**: `arriving → waiting → following → toTub → bathing → leaving`
- **데이터 주도 설계**: 밸런스·대사·맵 수정은 `data.js`만 고치면 됨
- **저장**: 매 영업일 시작 시 `localStorage` 자동 저장 → 타이틀의 "이어하기"

## AI 에셋으로 교체하기

`js/data.js` 맨 아래 `ASSET_MANIFEST`에 이미지를 등록하면 해당 캐릭터/오브젝트는 도형 대신 이미지로 그려집니다.

```js
const ASSET_MANIFEST = {
  chihiro:  { src: 'assets/chihiro.png',  w: 48, h: 64, ax: 0.5, ay: 0.95 }, // 발밑 기준
  kaonashi: { src: 'assets/kaonashi.png', w: 56, h: 90, ax: 0.5, ay: 0.97 },
  moss:     { src: 'assets/moss.png',     w: 44, h: 48 },                    // 손님 타입 키
  tree:     { src: 'assets/tree.png',     w: 90, h: 120, ay: 0.85 },         // 오브젝트 kind 키
};
```

- 캐릭터 키: `chihiro`, `kaonashi`, `moss` `lantern` `river` `mushroom` `fox` `turtle` `rabbit` `frog`
- 오브젝트 키: `tree` `patch` `shelf` `crate` `furnace` `counter` (탕은 상태 표현 때문에 코드 렌더 유지)
- 권장 규격: 투명 PNG, 쿼터뷰 시점, 타일 1칸 = 64×32px 기준
