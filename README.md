# 신들의 손님맞이

> 신들이 방문하는 목욕탕에서 16일 동안 손님을 맞이하는 **2D 경영 + 탐험 시뮬레이션**
> 《센과 치히로의 행방불명》에서 영감을 받은 **비공식·비영리 팬게임** · 게임 기획/구현 포트폴리오

| 항목 | 내용 |
|---|---|
| 플랫폼 | PC 웹 (Chrome / Edge / Safari 최신) |
| 기술 | HTML · CSS · Vanilla JavaScript (Canvas 2D, WebAudio) — 외부 라이브러리 없음 |
| 그래픽 | 쿼터뷰(아이소메트릭) · 현재는 코드로 그린 플레이스홀더 → AI 에셋으로 교체 가능 |
| 조작 | WASD 이동 + 마우스 상호작용 |
| 분량 | 게임 내 16일 (하루 영업 약 3~4분 + 마감 정리) · 특별한 손님 5명 · 엔딩 6종 (잘 모신 특별한 손님 수 0~5명) |

## 실행 방법

빌드 과정이 없습니다. 아래 중 하나로 실행하세요.

- `index.html` 을 브라우저로 직접 열기
- 또는 로컬 서버: `python3 -m http.server 8642` 실행 후 `http://localhost:8642`

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 이동 (한글 입력 상태에서도 동작) |
| 마우스 클릭 | 손님·탕·약재·단서·구역 이동 문과 상호작용. 멀리 있으면 자동으로 걸어감 |
| `Space` / `E` | 가장 가까운 대상과 상호작용 |
| `Space` (꾹) | 탕 패널에서 불 지피기 |
| `1`~`3` | 대화 선택지 (`Space`·`Enter`는 강조된 선택지) |
| `J` / `Esc` / `M` | 단서 수첩 / 일시정지 / 소리 |

## 게임 루프

```
손님 도착(접수대) → 주문 듣기(온도·약재) → 목욕탕 탐험·약재 채집
→ 탕 준비(불 지피기로 온도 맞추기 + 약재 넣기) → 손님 안내 → 목욕 → ★1~5 평가
→ 탕 청소 → (반복) → 영업 종료 정산 → 상점 업그레이드 → 다음 날
```

### 평가 공식 (`js/game.js` → `rate()`)

| 요소 | 감점 |
|---|---|
| 온도 차이 0~1°C | 없음 |
| 온도 차이 2°C / 3~4°C / 5°C 이상 | −1 / −2 / −3 |
| 요청 약재 누락 (가지당) | −2 |
| 요청하지 않은 약재 (가지당) | −1 |
| 인내심 25% 미만에서 응대 | −1 |
| 목욕 중 온도가 어긋난 시간 20% 초과 / 50% 초과 | −1 / −2 |
| 사이 나쁜 손님이 옆 탕에 | −1 (사이 좋으면 팁 +10냥) |

- 별점 1~5 → 보상 `별×8냥` (+5점이면 12냥 보너스), 점수 `별×20`
- 인내심이 바닥나 돌아간 손님 / 영업 마감 때 아직 대기 중이던 손님은 0점으로 평판에 반영

### 맵 구조: 목욕탕 ↔ 탐험 구역 (`js/data.js` → `SCENES`)

- **메인 목욕탕**: 접수대, 탕 4개(한 줄), 복도, 보일러실 — 손님은 항상 여기에만 있음
- **탐험 구역 2곳**: 정원(유자·쑥·연못·국화·솔잎) / 약재 창고(감초·계피·박하·대추·생강). 복도 왼쪽 끝의 문으로 드나들며, 문을 지나면 장면이 페이드 전환
- 탕 앞에서 약재까지 편도 약 5초 (가장 먼 유자나무는 약 6초)
- 정원(13×10)·약재 창고(12×10)의 빈 바닥은 앞으로 추가할 채집 지점(탕 재료) 자리
- 탐험 구역에 있는 동안에도 영업 시간·인내심·탕 냉각·목욕은 계속 진행 → 화면 위 **목욕탕 소식** 띠에 새 손님, 인내심 낮은 손님, 식는 탕, 장작 부족 등을 표시
- 따라오던 손님은 구역으로 따라오지 않고 자리로 돌아감
- 보일러실은 탕 재가열·장작 보충 부담 때문에 메인 목욕탕에 그대로 둠 (기획서 v2.0의 '완전 분리·편도 8초'를 줄인 절충안)

### 탕 온도 변화 · 보일러 (`js/data.js` → `TUB_COOL_RATE`, `BOILER`)

- 물을 받은 탕은 **12초에 1°C씩 식음** (최저 30°C). 입장 온도로 기본 평가, 목욕 중 온도 유지로 추가 평가
- 목욕 중 요청 온도에서 1.5°C 이상 벗어나면 손님이 "차가워!/뜨거워!" 불평 → 목욕 중인 탕을 클릭해 온도만 조절 가능
- 불 지피기는 **보일러 장작**을 소모 (불 지필 때 초당 4, 평소 초당 0.12). 장작이 떨어지면 가열 속도 35%
- 보일러실 가마를 클릭하면 1.2초 동안 장작을 넣어 100%로 채움

### 손님 궁합 (`js/data.js` → `GUEST_RELATIONS`, `TUB_NEIGHBORS`)

- 탕은 욕탕 안쪽 벽을 따라 한 줄로 배치 (네 번째 탕도 같은 줄 끝에 추가) · 옆 탕 관계: 탕1–탕2, 탕2–탕3, 탕3–탕4
- 사이 나쁨: 여우불 아가씨–강물 정령, 등롱 요괴–강물 정령, 돌거북 신–달토끼, 여우불 아가씨–연잎 개구리 신, 눈꽃 정령–여우불 아가씨, 눈꽃 정령–등롱 요괴, 방망이 도깨비–학 선인
- 사이 좋음: 이끼 노인–돌거북 신, 강물 정령–연잎 개구리 신, 버섯 할멈–이끼 노인, 달토끼–등롱 요괴, 학 선인–돌거북 신, 호랑나비 아씨–연잎 개구리 신, 방망이 도깨비–등롱 요괴
- 주문 카드·주문 대사·탕 툴팁에서 관계를 미리 확인 가능

### 영업 마감 규칙 (기획서 v2.0 기준)

- 02:00이 되면 **신규 접객 차단**: 새 손님이 오지 않고, 대기 중인 손님은 돌아감
- **안내·입욕·목욕 중인 손님은 끝까지 마무리** 가능 (안내 중인 손님은 남은 대기 시간 안에서)
- 남은 손님이 모두 떠나면 정산 화면으로 넘어감

### 특별한 손님 (`js/data.js` → `SPECIALS`, `SPECIAL_ORDER`, `CLUES`)

- **한 번에 한 분씩**: 이틀 동안 목욕탕 곳곳(정원·창고·욕탕·복도·보일러실)에 단서를 하루 2개씩 남기고, 사흘째 밤에 찾아와 접수대 옆에 선다
- 단서 4개 중 하나는 **그림자 단서** — 다가가 말을 걸면 그 손님의 모습이 잠깐 보이고 사라짐
- 그 손님의 단서를 **3개 이상** 모아야 손님으로 맞이할 수 있음. 주문은 `???`로 숨겨져 있어 단서(온도·약재 힌트)를 보고 탕을 준비
- 맞는 탕(온도 ±1°C, 약재 정확, 온도 유지)을 대접하면 보상(80~90냥, 점수 +100)과 **영구 선물**을 남김
- 손님이 다녀가면 다음 날부터 다음 특별한 손님의 단서가 나타남
- 강의 신 · 거미 할아범 · 산신 할머니 · 구름 이무기는 이 게임의 오리지널 디자인 (한국 민담 모티프 포함)

| 손님 | 단서/방문 | 정답 탕 | 선물 |
|---|---|---|---|
| 강의 신 | 2·3 / 4일차 | 39°C + 창포 | 맑은 물방울 — 탕 식는 속도 −30% |
| 거미 할아범 | 5·6 / 7일차 | 44°C + 감초 | 튼튼한 거미줄 끈 — 바구니 +1칸 |
| 산신 할머니 | 8·9 / 10일차 | 45°C + 솔잎 | 산신의 부적 — 손님 인내심 +15% |
| 구름 이무기 | 11·12 / 13일차 | 41°C + 박하 | 구름 구슬 — 보일러 장작 소모 −30% |
| 얼굴 없는 손님 | 14·15 / 16일차 | 37°C + 연꽃 | 연꽃 한 송이 |

- 단서 수첩(`J`)은 특별한 손님별 탭으로 나뉨: 단서 진행 중·지난 손님은 열리고, 아직 오지 않은 손님은 `???`(시작 일차 표시). 방문 전에는 별칭(예: '진흙 손님'), 만난 뒤에는 이름으로 표시

### 엔딩 분기

16일차가 끝나면 **잘 모신(단서대로 탕을 대접한) 특별한 손님 수**에 따라 엔딩이 갈립니다. 잘 모신 손님 한 명마다 선물 하나를 받으므로, 엔딩 이름이 곧 받은 선물 수입니다.

| 잘 모신 손님 | 엔딩 |
| --- | --- |
| 0명 | 「빈 선반」 |
| 1명 | 「작은 인연 하나」 |
| 2명 | 「두 개의 선물」 |
| 3명 | 「세 개의 선물」 |
| 4명 | 「거의 다 채운 선반」 |
| 5명 | 「모든 손님의 미소」 (얼굴 없는 손님까지 — 마지막 밤 "금 대신 탕을 준비해 드릴게요" → 37°C + 연꽃 탕) |

- 예: 강의 신·거미 할아범·산신 할머니만 잘 모시고 그 뒤로 놓치면 → 「세 개의 선물」
- 엔딩 글에는 실제로 모신 손님 이름과 받은 선물 이름이 들어감 (예: "선반 위에 맑은 물방울, 튼튼한 거미줄 끈과 산신의 부적이 놓였다.")
- **선물 선반**: 다섯 자리 중 모신 손님은 초상화·선물 이름, 못 모신 손님은 실루엣·`???`(별칭 표시)
- 얼굴 없는 손님에게 한 마지막 선택(금을 받음 / 거절 / 무시 / 탕이 어긋남)은 엔딩 글 끝 한 줄로 남음 (5명 엔딩 제외)
- 그 아래 평판 등급(S/A/B/C)과 총점·평균 평판·맞이한 손님·놓친 손님

### 구현 포인트
- **소리 (파일 없이 WebAudio로 합성)**: 손님 도착 시 문 위 놋쇠 종 '딸랑-딸랑'(`Sfx` 의 `doorbell` — 짧은 타격 잡음 + 종의 비조화 배음이 길게 울리며 세 번 흔들림). 배경음악(`Bgm`, `BGM_SONGS`)은 두 곡이 화면에 따라 1.5초 겹치며 바뀜 — 영업 중(일차 시작·정산 포함)은 요나누키 오음계의 거문고 같은 뜯는 소리 곡(76bpm), 타이틀·이야기·엔딩은 몽환적인 곡(64bpm — 맑은 7화음 Dmaj7·Bm7·Gmaj7·Aadd9이 천천히 부풀고, 오르골·첼레스타 같은 종소리 분산화음이 흩어지며, 메아리를 길고 깊게). 멜로디는 매번 조금씩 새로 만들어짐. **손님 말소리(동물의 숲 느낌)**: 접수대에서 손님과 대화창이 뜨면 글자가 한 자씩 찍히며 손님마다 다른 목소리로 웅얼거림(`Voice`, `VOICES` — 일반 손님 12종 + 특별한 손님 5명). 한글 한 글자마다 모음(ㅏ·ㅔ·ㅓ·ㅗ·ㅜ·ㅡ·ㅣ)에 맞춘 공명 필터로 짧은 소리를 내고, ㅅ·ㅊ·ㅎ 같은 자음엔 잇소리를 붙임. 손님별로 높이·음색·빠르기·떨림·숨소리가 다름(예: 돌거북 신은 아주 낮고 느리게, 달토끼는 높고 빠르게, 얼굴 없는 손님은 '아… 아…' 낮은 숨소리). 「」가 있는 대사는 따옴표 안만 소리 내고 서술은 조용히 찍힘. 말하는 중 Space/Enter나 글자 클릭 → 글을 바로 끝까지 보여 줌(한 번 더 누르면 선택). 타이틀에서도 첫 클릭·키 입력 뒤 서서히 커지고, 소리 끄기(`M`)로 함께 멈춤

- **쿼터뷰 렌더링**: 월드 좌표(타일) ↔ 화면 좌표 변환, `x+y` 기준 깊이 정렬, 주인공을 가리는 벽·문·오브젝트(탕·선반·나무·보일러 가마 등) 자동 반투명 — 오브젝트는 바닥 마름모를 그림 높이만큼 늘린 모양 안에 주인공 몸이 들어가면 따로 깐 캔버스에 그려 통째로 옅게 얹음(`hidesPlayer`, `faded`). 오브젝트 바로 앞에 붙은 벽은 그 오브젝트보다 나중에 그려, 앞 벽에 붙은 보일러 가마가 낮은 벽 위로 튀어나오지 않게 함
- **마우스 피킹**: 바닥 투영 + 오브젝트 높이만큼 위로 훑는 방식으로 키 큰 오브젝트(나무, 선반)도 정확히 클릭
- **클릭 이동**: 멀리 있는 대상을 클릭하면 BFS로 경로를 찾아 걸어간 뒤 자동 상호작용
- **손님 AI 상태 머신**: `arriving → waiting → following → toTub → bathing → leaving`
- **데이터 주도 설계**: 밸런스·대사·맵 수정은 `data.js`만 고치면 됨
- **저장**: 매 영업일 시작 시 `localStorage` 자동 저장 → 타이틀의 "이어하기"
